# Revenue atom carousel

Draft LinkedIn / Instagram carousel for Growth Labs. Copy is locked from the studio review file [`review.json`](review.json).

- [`review.json`](review.json) — studio export (source of truth)
- [`COPY.md`](COPY.md) — slide copy, captions, alt text
- [`POSTING.md`](POSTING.md) — how to publish
- [`slides.html`](slides.html) — 1080×1350 branded slides
- [`linkedin.pdf`](linkedin.pdf) — LinkedIn document
- [`exports/`](exports/) — PNG sequence

Rebuild:

```bash
node export-slides.mjs
```
