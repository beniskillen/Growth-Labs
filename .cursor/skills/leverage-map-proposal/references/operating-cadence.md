# 30 / 90-day operating cadence

If it cannot be staffed, dated, and killed, it does not go in the proposal.

## Assignment schema (every row)

| Field | Rule |
| --- | --- |
| Action | Verb + artefact. Not “work on funnel”. |
| Window | `30` or `90` |
| Outcome | Leading indicator (bookings, conversations, cash, artefact shipped) |
| Owner | A named human |
| Seat status | `Named` / `UNASSIGNED — needs owner by {date}` / `Client to appoint` / `Growth Labs` / `Bench / partner` |
| Hours/wk | Honest load |
| Depends on | Other rows or decisions |
| Done when | Observable artefact or number |
| Kill / pivot if | The falsifier |

Unassigned rows are **pink** on FigJam and the **client ask**: appoint or cut.

No row without a date. No date without done-when. No 90-day item required for the 30-day bet to succeed.

## Day 0–30 — prove the constraint fix (More / Better)

Purpose: move the **one leak** with owned demand. One new-channel test max, with a kill date.

Default shape (adapt to the brief):

1. Freeze avatar, promise, ticket/backend boundary, date hypothesis (what would have to be true)
2. Scoreboard live: impressions, UVs, CTR, bookings, show-ups, close, sponsor conversations, cash, hours
3. Lead magnet / nurture path shipped — **one** variant
4. Booking path that is not the current leak (worked example: DM → calendar with 0% conversion — replace with **this** path)
5. N buyer conversations and N sponsor conversations — from **this** capacity, not ambition
6. One flagship custom sponsor thesis issued (not ten decks)
7. COGS band + cash gates written; no unfunded commitment
8. RACI: every workstream Named or UNASSIGNED-by-date
9. Decision log: approved / rejected / needs evidence / deferred

**30-day pass/fail:** **this** constraint metric moved, **or** the path is officially killed and replaced. Worked example (AIP only): booking rate no longer 0% on a stated sample, **or** direct-to-call killed for a tripwire/application. Write the pass/fail in **this** metric.

## Day 31–90 — install the engine (then New)

Only scale what the 30-day scoreboard proved.

1. Always-on owned demand + one proven paid or partner channel
2. Affiliates / JVs / speaker distribution as lead getters **after** conversion works
3. Top-10 sponsors: custom where warm, tier downsell otherwise
4. Call/fulfilment capacity hired **or** supply metered
5. Workback to flagship date with cash gates
6. Backend / continuity only if 30-day take-up supports it (else planning-case)
7. Clip / stream / content engine as a **costed system**, not a slogan
8. 30-day UNASSIGNED seats gone or explicitly cut

**90-day pass/fail:** CAC (or proxy) known on at least one path; one cash sponsor **or** a dated no; fulfilment matches volume; unassigned seats cleared.

## Cadence (do not invent a second rhythm)

If the client already has one, use it. Default:

- **Monday** — owner updates, next actions dated
- **Wednesday** — 30-min WIP on lead measures, budget, blockers
- **Friday** — decision log, pipeline movement, hours, next-week commitments

## Capacity maths (required when conversations are the product)

```
required conversations / working days in window = conversations per day
× loaded minutes = hours/wk
```

If hours/wk exceed named owners, either hire, meter supply, or cut the doctrine. Write the closer-days. Do not hide them in a vision paragraph.

## What would have to be true (date / scale decisions)

For each date hypothesis on **this** brief (worked example was April vs October), a table:

| Gate | Evidence required | Owner | By when | If miss → |
| --- | --- | --- | --- | --- |
| Conversion proof | Booking rate on sample N | | | Slip date / kill path |
| Sponsor cash | Deposit invoiced | | | Do not lock venue |
| Speaker in writing | Term sheet | | | Do not market the name |
| Production owner | Named human | | | UNASSIGNED stays red |
| Fulfilment | Closer hired or cap | | | Meter seats |

## Parking lot

Anything that fails the 30-day table goes here with a re-entry condition (“after booking rate ≥ X” / “after $Y sponsor cash”). Parking lot is a feature. It keeps the cover palatable.
