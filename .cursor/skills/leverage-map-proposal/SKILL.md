# Leverage Map Proposal

Produce a palatable commercial architecture a sceptical operator can run on Monday. The proposal **is** the product demo of Growth Labs. If the client cannot execute the next 14 days from the 30-day table, it does not ship.

This is not a transcript dump. Method: constraint → three offers → money model → valence economics → custom integrations → COGS → 30/90 with owners → FigJam.

## When to use

- Sponsorship / event growth proposal
- Leverage map, impression inventory, media value
- Custom sponsor decks or category-job packaging
- Hormozi-style offer + money model
- 30/90 operating plan with owners
- “Show what Growth Labs can execute” for a strategic scope

## Gates (never skip)

- Never invent metrics. Missing analytics = `Data gap`.
- Never auto-send outreach, invoices, or contracts.
- Split **private** (trust, personal history, undeclared hours) from **shareable**.
- Search existing Notion first. Link and patch. Do not spawn a second source of truth.
- Every action is `Named` or `UNASSIGNED — needs owner by {date}`. Unassigned rows **are** the client ask.
- Kitchen-sink lanes stay on the scope map as **Not now** or **Out**.
- Unproven conversion/take-up rates are labelled **planning-case**.
- Media-value claims need a CPM source **and** an impression source, else `Data gap`.
- Do not scale a channel until the conversion system holds water.
- If the 30-day table cannot be staffed, cut scope until it can.
- Australian spelling. USD unless the brief says otherwise.

## Pipeline

```
ingest → research → offer clinic + money model → Growth Labs scope map
      → Notion architecture → 30/90 with owners → FigJam → two-page exec pack
```

### 1. Ingest

Collect: transcript / brief, contract deliverables, vision/mission, current funnel numbers, existing Notion/Slack, team RACI, date hypotheses, COGS if any.

Output a one-page **intake card**: client, event/programme names, north-star numbers (stated vs evidenced), current constraint hypothesis, private vs shareable split.

### 2. Research

Run every module in [references/research-playbook.md](references/research-playbook.md). Cite sources. Flag unknowns. Do not put hoped-for impressions in a deck.

### 3. Offer clinic + money model

Force **three distinct offers** (never one blob):

1. **Client offer** — what they buy from Growth Labs this cycle
2. **Buyer offer** — what their customer buys (ticket / programme)
3. **Sponsor offer** — category job + attribution + LTV; custom first, tiers as downsell

Run the value equation and “what would have to be true” tables. Build cash timing, not only totals. See [references/hormozi-fladlien.md](references/hormozi-fladlien.md).

### 4. Scope map

Map **client constraint → one primary Growth Labs install → optional bench**. Tag every lane In 30 / In 90 / Not now / Out. See [references/growth-labs-scopes.md](references/growth-labs-scopes.md).

### 5. Notion architecture

Follow [references/notion-architecture.md](references/notion-architecture.md). Hub + children. Reuse existing page IDs.

### 6. 30/90 with owners

Follow [references/operating-cadence.md](references/operating-cadence.md). Full assignment schema. No 90-day item that the 30-day bet depends on.

### 7. FigJam

Follow [references/figjam-board.md](references/figjam-board.md). New FigJam **draft**. Embed the URL on the Notion hub.

### 8. Exec pack

Write the hub cover as a **two-page** artefact: one constraint, one 30-day bet, one ask, three numbers, UNASSIGNED count, FigJam link. Everything else is appendix.

## Palatability layers (client artefact)

The Loom / operator download is not the client artefact.

1. Cover (2 pages)
2. Money model + 30/90
3. FigJam leverage map
4. Appendix (competitive, COGS, top-100, custom theses, citations)

If a recommendation cannot survive the 30-day table (owner, hours, leading indicator, done-when), it goes to **Not now / 90+** or **Parking lot**.

## Output contract (failed run if any missing)

- Named constraint with evidence
- Three offers, separated
- Money model with cash timing + planning-case labels
- Scope map with In 30 / In 90 / Not now / Out
- Notion hub URL
- 30-day table + 90-day table, every row Named or UNASSIGNED-by-date
- FigJam draft URL on the hub
- One primary CTA
- Decision log (approved / rejected / needs evidence / deferred)
