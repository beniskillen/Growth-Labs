# Maintenance Cadence

> The brain only works if it stays true. Total upkeep: ~20 minutes a week, folded into rituals you already run.

## Daily — 0 minutes

Nothing. Do not touch this folder daily. Daily updates create noise, not memory.

## Weekly — ~10 min, inside the Friday close ritual

- Update `01-current-focus.md`: this week's checklist → shipped/slipped, write next week's 3–6 actions
- Add any new live deals; delete dead ones
- Append any decisions made this week to `09-decisions-log.md`

## Weekly — ~5 min, inside the Monday CEO review

- Sanity-check `02-active-vs-ceased-work.md` — did anything change scope?
- If yes, update it the same day and commit

## Fortnightly — ~5 min

- `03-clients-and-scope.md`: revenue, scope lines, status column

## Monthly — ~15 min, first Monday finance command centre

- `05-okrs-2026.md`: phase progress vs $20k p/m and <40-hr week
- Prune: any file section that no longer earns its tokens gets cut or pushed back to Notion

## Quarterly — ~30 min

- `06-miles-framework.md`: re-grade each level's status
- `07-cursor-rules.md` + `08-style-guide.md`: still true?
- Full read-through: if the whole folder takes more than 10 minutes to read, it is too big — compress

## Rules

1. Update on **change**, not on schedule, for `02-active-vs-ceased-work.md` — same day something ceases or starts
2. Any file over ~1,500 words gets split or summarised; depth belongs in Notion
3. Git-commit after every edit session (one-line message) so the brain is versioned
4. When Notion and this folder disagree, fix the folder immediately — it is the copy, not the original
