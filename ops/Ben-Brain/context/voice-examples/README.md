# Voice Examples — Ben

Real messages Ben has actually sent. Any agent writing in Ben's name reads these first
(`specs/01-bd-outreach-loop.md` AGENT BRIEFING, and Standing Rule 3 in the root README).

This is the single biggest lever on draft quality — an agent matches evidence it can see far
better than a described voice. The written voice rules live in
`../operating-brain/08-style-guide.md`; these files are the ground-truth samples that make those
rules concrete.

## What to drop in

Add 5–10 real messages, grouped by channel, as plain files here (e.g. `telegram.md`,
`linkedin.md`, `email.md`) or paste them into this README under the headings below. Label each
with its situation. Strip anything genuinely private; keep the phrasing intact.

```
[Telegram — warm lead follow-up]
<paste a real message>

[LinkedIn — reconnect with a founder]
<paste a real message>

[Email — audit invite]
<paste a real message>
```

After each calibration run, add 2–3 of Ben's best edits back here — that closes the loop on tone.
