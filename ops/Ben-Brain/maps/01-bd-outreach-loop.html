▸

Re-read the live Growth Labs objective page. Classify each contact: audit-path, partner/channel-path, or park. Communities are channels, not clients.

2

Gate: every action confirmed, or challenged with rationale

▸

Test each assigned Next Action against the objective, status, and last real interaction. Advances the funnel → execute as drafted. A better move exists → propose a replacement with reasoning shown. Never silently override.

Gate: read-aloud test — Ben could send it verbatim

▸

Channel-native drafts in Ben's voice. One per contact; an alternate angle only where the read is genuinely ambiguous. Every draft anchors on real context — zero invented history. Match context/voice-examples/.

4

Cadence reset AGENT

Gate: a future date or a deliberate, logged close-out

▸

Propose the new Next Contact date per the cadence matrix, plus the next-next action so the pipeline always has a forward move. Stated preferences beat the matrix — log the override.

Gate: the number first, then ready-to-send, judgment calls, flags, log line

▸

Assemble the run sheet from context/templates/run-sheet-template.md and present it. Score the run 0–5 on Congruence · Objective fit · Cadence sanity · Evidence · Completeness — loop on anything under 4 first.

⟡

REVIEW GATE — hard stop BEN

Produce the run sheet, then STOP and WAIT

▸

Ben reviews, fires the sends himself, and tells the agent which touches went out. No CRM write, no "sent" mark, no date moves until Ben confirms — however obvious the approval seems.

6

Write-back & log AGENT

Gate: CRM reflects only what Ben confirmed; log line written

▸

For confirmed sends only, update the CRM (Next Contact, Next Action, Status, notes). Append the run to the log (context/templates/run-log-template.md) — every run, even empty ones. A loop without a log is a cron job with vibes.

Cadence matrix (default by warmth)

In ConversationReply <24h; follow up 2–3 days after silence
Warm Lead5–7 days between touches
Active (partners)7–14 days, value-led — never pitch
To Review / newFirst touch within 3 days of triage
Cold (re-activation)30+ day spacing, max 2/quarter

Guardrails

  • Agent never sends — drafts only.
  • Do Not Contact is absolute.
  • One-item menu — only the audit is sold; no pricing / ladder in a first touch.
  • Three-strike rotation → rotate channel once, then park 30 days.
  • No two identical messages, ever. "Just bumping this" is banned.
  • Never fabricate shared history — flag the gap.
  • Cash base first; never rev-share-only.

Graduation (trust ladder)

Stays manual & fully gated until 10 consecutive runs with ≥80% of drafts approved unedited (tracked in the log line). Only then decide whether a scheduled morning run gets added — and which tiers, if any, graduate past draft-only.
